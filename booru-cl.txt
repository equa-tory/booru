  - The remaining ~120 MiB per worker is the CUDA context. "Restart workers too"
    releases that.

  Download and delete
  - Each model has its own download and delete button. Delete is refused while
    that model is the selected main tagger or an AI task is running.

  Main tagger selector
  - You can pick Default, PixAI or My model. PixAI shows a warning because it
    has no rating tags and uses a different vocabulary.

  My model
  - It is an exact copy of the default model plus extra learned tags. The clone
    is checked for identical output, and it was bit-identical on the real
    default model.
  - To teach it:
    a. Clone it (about 13 seconds).
    b. Select posts, press 🎓 teach AI, and mark them as "show it" or "don't".
       "Don't" also removes the tag.
    c. Press train in settings → My model, which takes seconds.
    d. Optionally index the library, then preview the posts it is most sure
       about and review the ones it is least sure about.
    e. Apply to the library, which can be undone.
  - Tag with it automatically by choosing My model as the main tagger.

  How well it learns
  - I tested on a copy of your database, with real features from your GPU. I
    taught it four existing characters, from 0.17% to 2.7% of your library, as
    if they were new, using 23–30 examples each.
  - On unseen posts it separated them with accuracy scores (AUC) of 0.989,
    0.990, 0.998 and 1.000.
  - For rare things even a small false-positive rate adds up: 0.7% of a 28k
    library is about 200 wrong tags. So the apply dialog shows how many posts
    would be tagged, and you should cancel if that number is far above what you
    expect.
